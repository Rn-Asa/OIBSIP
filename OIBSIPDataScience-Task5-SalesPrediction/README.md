 Sales Prediction Using Python

Overview

This project uses Machine Learning to predict product sales based on advertising expenditure across different media channels: TV, Radio, and Newspaper.

 Objective

To build and evaluate regression models that predict product sales based on advertising spending.

 Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

 Project Steps

- Loaded and explored the advertising dataset
- Checked for missing values and generated descriptive statistics
- Created a pairplot to explore relationships between features
- Created scatter plots for Sales vs TV, Radio, and Newspaper advertising spend
- Created a correlation matrix heatmap
- Split the dataset into training and testing sets
- Trained a Linear Regression model
- Trained an additional regression model
- Evaluated the models using MAE, RMSE, and R² Score
- Created a residual plot for the best-performing model
- Analyzed which advertising channel had the highest impact on sales

Key Insight

The analysis shows how advertising expenditure across different media channels can influence product sales. Model coefficients and feature importance were used to identify the channels with the strongest impact on sales.

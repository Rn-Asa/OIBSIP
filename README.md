This repository contains the Data Science and Machine Learning projects I completed as part of my Data Science internship. These projects demonstrate my growing knowledge of data analysis, data visualization, machine learning, and model evaluation using Python.

Task 1: Iris Flower Classification

Project Overview

This project focuses on building machine learning models to classify Iris flowers into three species:

- Setosa
- Versicolor
- Virginica

The classification is based on physical measurements such as sepal length, sepal width, petal length, and petal width.

Highlights

- Loaded the Iris dataset directly from Scikit-learn
- Performed Exploratory Data Analysis (EDA)
- Checked dataset shape, data types, and missing values
- Created pairplots and boxplots for visualization
- Analyzed the most discriminative features
- Split the dataset into training and testing sets
- Trained multiple classification models
- Compared model performance and identified the best-performing model

Models Used

- Logistic Regression
- K-Nearest Neighbours (KNN)
- Decision Tree Classifier
- Random Forest Classifier

Evaluation Metrics

- Accuracy Score
- Confusion Matrix
- Precision
- Recall
- F1-Score

Task 2: Unemployment Analysis with Python

Project Overview

This project performs Exploratory Data Analysis on unemployment data in India to identify regional and temporal trends, with particular attention to the impact of the COVID-19 pandemic.

Highlights

- Loaded and inspected the unemployment dataset
- Checked dataset shape, data types, and missing values
- Converted the Date column to datetime format
- Analyzed average unemployment rates across different states
- Examined month-wise unemployment trends
- Created time-series visualizations for selected states
- Identified the top 10 states with the highest average unemployment rates
- Created a correlation heatmap
- Compared unemployment rates before and after COVID-19
- Documented observations and insights from the visualizations

key Analysis Areas

- Region-wise unemployment analysis
- Monthly unemployment trends
- Time-series analysis
- Correlation analysis
- Pre-COVID vs Post-COVID comparison

Evaluation and Analysis

The project focused on identifying patterns and trends using:

- Average unemployment rates
- Time-series trends
- Correlation analysis
- Regional comparisons
- Pre-COVID and Post-COVID mean comparisons

Task 5: Sales Prediction Using Python

Project Overview

This project uses machine learning regression models to predict product sales based on advertising expenditure across three media channels:

- TV
- Radio
- Newspaper

Highlights

- Loaded and explored the advertising dataset
- Checked for missing values
- Generated descriptive statistics
- Created a pairplot to explore relationships between variables
- Created scatter plots for advertising spend and sales
- Generated a correlation matrix heatmap
- Split the dataset into training and testing sets
- Trained a Linear Regression model as the baseline
- Trained an additional regression model
- Compared model performance
- Created a residual plot for the best-performing model
- Analyzed which advertising channel had the greatest impact on sales

 Models Used

- Linear Regression
- Random Forest Regressor

Evaluation Metrics

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

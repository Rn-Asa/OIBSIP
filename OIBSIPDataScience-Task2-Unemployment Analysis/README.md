Unemployment Analysis with Python

Overview

This project analyzes unemployment data in India to identify regional and monthly trends, with a focus on the impact of the COVID-19 pandemic on unemployment rates.

Objective

To perform Exploratory Data Analysis (EDA) on unemployment data and uncover trends across different states and time periods.

Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

Project Steps

- Loaded and inspected the unemployment dataset
- Checked the dataset shape, data types, and missing values
- Converted the Date column to datetime format
- Analyzed average unemployment rates across different states
- Examined month-wise unemployment trends
- Created time-series visualizations for selected states
- Identified the top 10 states with the highest average unemployment rates
- Created a correlation heatmap
- Compared unemployment rates before and after COVID-19

Key Insight

The analysis showed that unemployment rates varied across different states and changed over time. The data also revealed noticeable changes in unemployment patterns around the COVID-19 period.
